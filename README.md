# Транслятор учебного конфигурационного языка (Вариант 20)

CLI-инструмент для преобразования учебного конфигурационного языка в формат XML.

## Синтаксис
- Однострочные комментарии: `* комментарий`
- Числа (включая экспоненциальную форму): `10`, `1.5e2`
- Строки: `'строка'`
- Массивы: `( 1, 2, 3 )`
- Константы: `def имя = значение`
- Префиксные выражения: `{+ a b}`, `{- a b}`, `{ord 'A'}`, `{sort ( 3, 1, 2 )}`

## Запуск
```bash
python src/main.py -i examples/web_server.conf
python src/main.py -i examples/game_config.conf
